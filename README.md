# Hoja de vida - Cristian

Página web con mi hoja de vida para el curso Introducción a los lenguajes de Internet (UCompensar).

Páginas:
- index.html: inicio, perfil, áreas de trabajo y habilidades
- experiencia.html: experiencia laboral y tabla de herramientas
- formacion.html: estudios, cursos e idiomas
- contacto.html: datos de contacto y formulario

Los estilos están en css/styles.css y el JavaScript en js/main.js.
